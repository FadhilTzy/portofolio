## 📌 Features

- Responsive modern UI
- Cyberpunk / futuristic design
- Interactive cursor effect
- Smooth scrolling navigation
- Project showcase section
- About & team section
- Animated components
- Fast performance with Vite

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- TypeScript
- ESLint
